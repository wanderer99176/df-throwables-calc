# DF 投掷物尺子 · 弹道计算器

《三角洲行动》干员投掷物的**离线弹道尺子与定点打击计算器**（露娜 5s 手雷 / 电击箭矢、乌鲁鲁燃烧瓶、牧羊人 2s 手雷等）。

当前便携版：**[v0.3.8](https://github.com/wanderer99176/df-throwables-calc/releases/tag/v0.3.8)** · `DF-Throwables-Ruler-0.3.8-portable.exe`

- 按目标距离反解视角仰角 α，并给出多种身位 / 动作方案  
- **弹道侧边尺**（左）：跟随 / 目标标注 / 全角距离刻度  
- **光学仰角遮罩**（右）：全程点穿，按 FOV 读地平线（约 ±34°）；可调左右位置与浓度  
- 浏览器 / 桌面完整计算器：地图射程圈、同爆点多方案表、战术弹道图  
- 计算器排版随窗口**横/竖自动切换**；战术弹道图随窗口缩放等比铺满（不裁切）  

仓库 / 下载：<https://github.com/wanderer99176/df-throwables-calc>

> **合规说明**：非外挂、非注入、非读取、不捕捉屏幕。仅本地计算与对照；大仰角用弹道尺或 M7 火控镜，小仰角可用光学遮罩看地平线。

数据与思路参考：[BV1K1hE6VE2F](https://www.bilibili.com/video/BV1K1hE6VE2F/)（@可可龙 等测算内容）。

## 普通用户：下载即用（推荐）

不需要安装 Node.js，也不用敲命令。

1. 打开 [Releases（发布页）](https://github.com/wanderer99176/df-throwables-calc/releases)  
2. 下载最新的 **`DF-Throwables-Ruler-*-portable.exe`**（Windows 64 位便携版，当前推荐 **0.3.8**）  
3. 放到任意文件夹，**双击运行**即可  

启动后**只打开计算器**（排版随窗口横/竖自动切换；**刻度详情**默认开启）。顶栏可按需打开侧栏：

| 按钮 | 说明 |
| --- | --- |
| **弹道尺** | 左侧跟随尺（全角距离 / 目标标注） |
| **仰角遮罩** | 右侧光学遮罩（全程点穿，约 ±34°；位置 / 浓度可调） |

再次双击便携包：会先结束旧进程，再只开计算器（不会越开越多）。若仍异常，可先运行仓库里的 `kill-leftovers.bat` 清残留。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+H` | 显隐弹道尺 |
| `Ctrl+Shift+M` | 显隐光学遮罩 |
| `Ctrl+Shift+F` / `0` / `X` | 跟随 / 归零 / 穿透（弹道尺） |

游戏建议**无边框窗口**。

浏览器版仍可用 `npm run dev`（见「开发者」）。

## 仰角遮罩

仅 **光学** 刻度（按 FOV 透视，约 ±FOV/2，常见约 ±34°）。全程点穿；与弹道尺分工不同，**两者都保留**。

计算器顶栏可调：
- **位置**：左 / 偏左 / 中 / 偏右 / 右，或输入 0～100%
- **浓度**：0 更淡、100 更实，避免挡画面
- FOV / 画幅

默认贴在**左边**。右上角 **×** 可关；`Ctrl+Shift+M` 显隐。

## 桌面悬浮侧边尺（弹道）

左侧置顶窄窗：跟随绿线、目标红虚、姿态九宫格、距离/时间刻度。与光学遮罩分工不同，**两者都保留**。

### 顶栏按钮

| 按钮 | 作用 |
| --- | --- |
| **跟随** | 绿线随鼠标相对位移（默认开启） |
| **归零** | 仰角回到 0°（先对准地平线） |
| **穿透** | 鼠标点穿到游戏；移到顶栏 / 标尺上仍可点控件 |
| **透明度** | 弹出滑块：只淡化**烟玻底色**，刻度保持清晰；可透视背后画面 |
| **极简** | 只留刻度尺（隐藏顶栏与底部面板），**保持进入前的标尺高度比例** |
| **×** | 关闭侧边尺（不影响计算器窗口） |

#### 透明度

- 滑块范围 **-100～100**，默认 **0**（半透烟玻）  
- **-100**：底色几乎消失，刻度只剩一点痕迹  
- **100**：实底  
- 拖动为预览；点 **保存** 才写入本地；关掉弹窗不保存则恢复原值  

#### 底部面板（两套读数，互不抢线）

| 区块 | 作用 |
| --- | --- |
| **跟随实时** | 绿线当前 α / **掐雷时间** / 落地申报距离 R / Δh；跟随或拖标尺时自动更新 |
| **目标标注 · 红虚** | 手动填 R、Δh → 反解并钉死**红色虚线**；跟随移动**不会**改写这两格，也不会把红虚拽走 |
| **姿态九宫格** | 站进/蹲进/趴进 · 站走/蹲走/趴走 · 站跳/走跳/跑跳；换姿态只更新红虚解，不硬拽绿线 |

标尺线含义：

- **绿线** = 当前仰角（跟随 / 拖动）  
- **红虚** = 目标标注仰角（对齐用）  
- **蓝虚** = 平地最远点（不随标注 Δh 挪动）  
- **橙虚** = 封顶 · **红实** = 0°  

#### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+F` | 鼠标跟随开/关 |
| `Ctrl+Shift+0` | 仰角归零 |
| `Ctrl+Shift+X` | 穿透开/关 |
| `Ctrl+Shift+H` | 显示 / 隐藏侧边尺 |
| `Esc` | 退出极简 / 关闭透明度弹窗 |

侧边尺内**禁用滚轮缩放**（避免把刻度间隙拉开）；数字框聚焦时仍可用滚轮改数值。

#### 绿线如何跟游戏准星一起动？

1. 订阅系统 **Raw Input** 鼠标相对位移（不是读游戏内存）  
2. `仰角变化 ≈ 鼠标纵向计数 × 灵敏度`  
3. 先看地平线 **归零**，再保持 **跟随**  

不注入、不读进程、不截屏识角。游戏请用**无边框窗口**；独占全屏时置顶窗可能被盖住。灵敏度因人而异，若绿线漂移可先归零再跟随。

## 功能

### 计算器主体（浏览器版）

- **干员 / 道具级联**：露娜（5s 手雷 + **电击箭矢点射**）、乌鲁鲁、牧羊人、威龙、蛊等；通用抛物线与特殊模型分开说明  
- **电击箭矢（点射·暂定）**：\(v_0\approx45\)、**无 +7.5° 补角**；侧栏显飞行时间；满蓄未建模  
- **技能效果条**：默认折叠；展开可见 v₀、g、补角、出手高、叠速、引信 / 伤害半径等  
- **参数旁 !**：R / Δh / 仰角 α / 向前位移等说明气泡  
- **动作与移动状态**（9 种）：静止 / 前移 / 跳投（走跳、跑跳）× 站·蹲·趴，自动叠真实 \(h_0\) 与移速  
- **读数区 5 格**：动作 · 仰头角度 · 水平距离 · 掐雷时间 · 倒计时截止（飞行）  
- **同爆点多方案表**：姿态 × 动作；主列「倒计时截止时间」从大到小；掐雷 / 移速 / θ 为次要列（可勾选显示）  
- **战术抛物线坐标系**：X/Y **同比例，一格 5m**；起投扇形、最高点、落地 / 空爆；拉环声圈在抛出点；**杀伤圈为有效半径**（默认 8m，渐变示意衰减）；图区随窗口等比缩放，矮窗不裁切  
- **排版**：窗口宽≥高 → 横屏（弹道图 + 仰角刻度并排）；高>宽 → 竖屏（上下堆叠、控件更紧凑）  
- **落地弹地**：默认关（掐雷落地炸）；开启后申报 = 落地 +3m，反解瞄准落地 = 申报 −3。快捷 **75m** 自动开，**72m** 自动关  
- **标尺**：橙虚封顶 / 蓝虚最远 / 红实 0° / **红虚目标仰角**；可点封顶·最远标签对齐；「刻度详情」默认开启  
- **快捷距离** 72 / 75 / 83 / 88～95m 与按干员战术卡  

### 地图射程圈

- **切换地图**（顺序与游戏内一致，**默认航天基地**）：  
  零号大坝 → 长弓溪谷 → **航天基地** → 巴克什 → 潮汐监狱 → AZ3  
- **比例尺方案**：每张图各自保存；内置默认 +「确认并保存」的用户方案按钮；标定少用，日常直接点方案  
- **设爆点 / 设我的位置**：手动切换，不自动跳转；两点水平距离**同步**上方目标距离与「同爆点多方案」表  
- **射程圈**：圈内 = 可用对应动作投到爆点；默认站立静止，可叠加蹲姿向前 / 向前跳投  
- **清除标点 / 恢复初始**：清标点与圈层选择；比例尺方案保留  

### 操作提示（浏览器）

- **滚轮改仰角**：仅当指针在轨迹图或右侧标尺上；划页面时不会误改数值  
- 数字框未聚焦时，滚轮只滚动页面  
- 点多方案表一行 = 切换动作 + 对齐仰角  
- 方向键 ↑↓（Shift 加大步进）

## 物理模型

| 参数 | 值 |
| --- | --- |
| 初速度 \(v_0\) | 手雷 27 m/s · **电击箭矢点射 ≈45 m/s（暂定）** |
| 重力 \(g\) | 9.8 m/s² |
| 隐藏补角 | 手雷 \(\theta = \alpha + 7.5^\circ\) · **电箭 \(\theta = \alpha\)** |
| 站 / 蹲 / 趴 / 跳 \(h_0\) | 1.8 / 1.0 / 0.3 / 2.4 m |
| 站走 / 蹲走 / 趴爬 / 跑跳 \(v_{\mathrm{move}}\) | **+3.8 / +2.3 / +1.15 / +5.5** m/s |
| 仰角上限 | 趴 45° / 其余 79.5° |
| 露娜引信 / 空爆 / 弹地 | 5 s / 约 4.7 s / +3 m · 0.3 s |
| 有效爆炸半径（面板） | 约 8 m（中心向外衰减） |

落点方程（平地 \(y=0\)）：

\[
t = \frac{v_0\sin\theta + \sqrt{(v_0\sin\theta)^2 + 2gh_0}}{g},\quad
R = (v_0\cos\theta + v_{\mathrm{move}})\, t
\]

**作者投射表**（校验用，α&lt;45° 时按 h₀=0.3）在 45° 有跳变：低段约 72.08 m、高段约 73.21 m；最远约 37.4° / 74.69 m。计算器默认按**真实身位高度**反解，故「站立静止打 72m」建议角约 **27°**（不是作者表习惯写的 30°——后者对应低释放高度标定）。

粗算极限（平地）：趴爬满角约 **79 m**；蹲走约 **85 m**；站走约 **91 m**；走跳约 **92 m**；跑跳更远（冲刺叠跳约值）。

### 72m 精选对照（模型反解，平地）

| 姿态 | 移动/动作 | 建议 α | 飞行约 | 说明 |
| --- | --- | --- | --- | --- |
| 站立 | 静止 | ≈27° | ≈3.24 s | 实战最推荐 |
| 蹲姿 | 向前移动 | ≈22° | ≈2.79 s | 半隐蔽平弧 |
| 站立 | 向前移动 | ≈19° | ≈2.57 s | 超低平弧直灌 |
| 趴下 | 静止 | 45° | ≈4.39 s | 头顶空爆 |
| 站立 | 原地起跳 | ≈26° | ≈3.20 s | 越低矮掩体 |
| 站立 | 向前走跳 | ≈18° | ≈2.55 s | 冲跃平拉 |

## 地图用法（简要）

1. 确认当前图（默认 **航天基地**）；换图用左上「切换地图」  
2. 首次或换图：打开「比例尺设置」→ 图上点两点 → **确认并保存**（之后点方案按钮即可）  
3. 「设爆点」点目标 → 「设我的位置」点站位 → 上方距离与多方案表自动更新  
4. 圈层勾选：站立静止（默认）/ 蹲姿向前 / 向前跳投  

圈为理想水平射程，**不含墙体挡弹**；比例尺不准时圈尺寸会偏。

## 使用建议

1. **桌面尺**：在**目标标注**填 R/Δh → 看红虚 → 开跟随把绿线对齐红虚后投出；需要透视时调烟玻透明度并保存  
2. **浏览器**：测距 → 输入距离（或用地图标两点）→ 在多方案表点选一行  
3. 游戏内用 **M7 火控镜**对齐该仰角后投出  
4. 越障用高抛；清点用低抛（表默认优先低抛）  
5. **FOV 不影响准星物理仰角**；勿死记 UI 边缘对齐  

数值来自社区测算复现，版本更新后请以靶场校准为准。跑跳移速 +5.5 m/s 为约值，可按实战再校。
