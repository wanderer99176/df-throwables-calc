# DF 投掷物尺子 · 弹道计算器

《三角洲行动》干员投掷物（露娜 5s 手雷/电击箭矢、乌鲁鲁燃烧瓶、牧羊人 2s 手雷等）的**离线弹道尺子与定点打击计算器**。

依据公开测算数据复现物理模型与「手雷投射表」，用于对照目标距离推算视角仰角，或按仰角读取落点距离与飞行时间。

> **合规说明**：非外挂、非注入、非读取、不捕捉屏幕。仅本地计算与后期对照；仰角请自行用游戏内 M7 火控镜等读角，或手动在本工具中调节。

数据与思路参考：[BV1K1hE6VE2F](https://www.bilibili.com/video/BV1K1hE6VE2F/)（@可可龙 等测算内容）。

## 快速开始

需要已安装 [Node.js](https://nodejs.org/)（含 npm）。在项目根目录打开终端：

### 浏览器版（调试 / 日常）

```bash
npm install
npm run dev
```

打开终端里提示的地址（默认 `http://127.0.0.1:5173`）。

### 游戏侧边置顶窗（推荐对照用）

**最简单**：双击 `start-desktop.bat`（或 `启动置顶尺子.bat`）。

脚本已改为纯英文 ASCII，避免中文 Windows 下 UTF-8 批处理乱码导致无法启动。

或在终端：

```bash
npm install
npm run desktop
```

会先构建网页，再打开**透明、无边框、始终置顶**的 Electron 小窗，默认贴在屏幕左侧，只显示尺子。

开发时热更新：

```bash
npm run desktop:dev
```

打成免安装便携版（输出到 `release/`）：

```bash
npm run package
```

#### 绿线如何跟游戏准星一起动？

原片右上角写「仅后期处理」，演示画面里的尺子**多半是剪辑叠上去的**。

你要的实时效果，合法做法正是你猜的那样：

1. 订阅系统 **Raw Input** 鼠标相对位移（不是读游戏内存）  
2. `仰角变化 ≈ 鼠标纵向计数 × 灵敏度`  
3. 先看地平线 **归零**（`Ctrl+Shift+0`），再开 **跟随**（`Ctrl+Shift+F`）

这与外挂无关：不注入、不读进程、不截屏识角。游戏请用**无边框窗口**；独占全屏时置顶窗可能被盖住。

> 灵敏度因人而异（DPI / 游戏 sens）。若绿线漂移，可先归零再跟随；后续版本可再补面板标定。

## 功能

- **技能效果条**：干员/道具下方；**默认折叠**，点「展开属性表」显示完整数值（含 v₀、g、出手高、叠速等）
- **参数旁 !**：R / Δh / 仰角 α（视角补偿+出手高）/「向前位移」旁（移速）
- **动作与移动状态**（合并枚举）：静止 / 前移 / 跳投 × 站·蹲·趴，自动叠真实 \(h_0\) 与移速
- **同爆点多方案表**：姿态 × 移动/动作（含原地/向前跳投）；主列「倒计时截止时间（飞行时间）」从大到小；掐雷/移速/θ 为次要列
- **战术抛物线坐标系**：中间 2D 图（X/Y **同比例，一格 5m**）；起投扇形、最高点、落地/空爆；**拉环声圈在抛出点**，**伤害圈跟爆点**（标注为**半径**，8m 半径水平跨度约 16m）；**落地弹地开关**（默认关；开启才画弹地 +3m，且反解瞄准落地=申报−3）；拖仰角实时变形
- **地图射程圈**：俯视图标定比例尺后，手动「设爆点」/「设我的位置」（不自动跳转）；两点间距同步上方目标距离与同爆点多方案表；默认站立静止圈，可叠加蹲姿向前 / 向前跳投；支持清除标点与恢复初始
- **落地弹地**：动作区开关；关=掐雷落地炸（申报=落地）；开=拉栓即投弹地（申报=落地+3m）。快捷 **75m** 自动勾选，**72m** 自动关闭
- **标尺**：默认只显示刻度与当前绿线；「刻度详情」打开后补全角度/距离/倒计时；**琥珀色封顶线** / **蓝色最远点** / **红色 0°**
- **高低差 Δh**、建议仰角、右侧垂直刻度轴
- **72 / 75 / 83 / 88～95m 速查**与按干员战术卡
- **置顶窗 / 鼠标跟随**（见上方桌面说明）

操作：滚轮或拖拽标尺微调仰角；方向键 ↑↓（Shift 加大步进）；点多方案表一行 = 切换动作 + 对齐仰角；点「封顶 / 最远点」标签可对齐；快捷 **75m** 自动打开落地弹地（瞄 72 落 → 弹至 75），**72m** 会关掉。

## 物理模型

| 参数 | 值 |
| --- | --- |
| 初速度 \(v_0\) | 27 m/s |
| 重力 \(g\) | 9.8 m/s² |
| 隐藏补角 | \(\theta = \alpha + 7.5^\circ\) |
| 站 / 蹲 / 趴 \(h_0\) | 1.8 / 1.0 / 0.3 m |
| 站走 / 蹲走 / 趴爬 \(v_{\mathrm{move}}\) | **+3.8 / +2.3 / +1.15** m/s |
| 仰角上限 | 趴 45° / 其余 79.5° |

落点方程（平地 \(y=0\)）：

\[
t = \frac{v_0\sin\theta + \sqrt{(v_0\sin\theta)^2 + 2gh_0}}{g},\quad
R = (v_0\cos\theta + v_{\mathrm{move}})\, t
\]

**作者投射表**（校验用，α&lt;45° 时按 h₀=0.3）在 45° 有跳变：低段约 72.08 m、高段约 73.21 m；最远约 37.4° / 74.69 m。计算器默认按**真实身位高度**反解，故「站立静止打 72m」建议角约 **27°**（不是作者表习惯写的 30°——后者对应低释放高度标定）。

粗算极限（平地）：趴爬满角约 **79 m**；蹲走约 **84 m**；站走约 **90+ m**。片中「83m 趴爬」在 \(v=1.15\) 下不可达，需蹲走或站走。

露娜：拉栓约 0.33 s、引信 5 s；飞行过久易空爆。

### 72m 精选对照（模型反解，平地）

| 姿态 | 移动/动作 | 建议 α | 飞行约 | 说明 |
| --- | --- | --- | --- | --- |
| 站立 | 静止 | ≈27° | ≈3.24 s | 实战最推荐 |
| 蹲姿 | 向前移动 | ≈22° | ≈2.79 s | 半隐蔽平弧 |
| 站立 | 向前移动 | ≈19° | ≈2.57 s | 超低平弧直灌 |
| 趴下 | 静止 | 45° | ≈4.39 s | 头顶空爆 |
| 站立 | 原地起跳 | ≈26° | ≈3.20 s | 越低矮掩体 |
| 站立 | 向前起跳 | ≈18° | ≈2.55 s | 冲跃平拉 |

表格列：**姿态 · 移动/动作状态 · α · 飞行时间 · 实战效果**；移速/θ 默认折叠。拖动距离时底部表实时刷新。

## 使用建议

1. 测距 → 输入距离 → 在下方多方案表点选一行（自动套用姿态/动作与仰角）  
2. 游戏内用 **M7 火控镜**对齐该仰角后投出  
3. 越障用高抛；清点用低抛（表默认优先低抛）  
4. **FOV 不影响准星物理仰角**；勿死记 UI 边缘对齐  

数值来自社区测算复现，版本更新后请以靶场校准为准。
